the local static preview and the public canonical domain. It deliberately
distinguishes verified results from account or integration steps that still
require an owner-only Google action.

## Performance observations

- HTML, CSS and JavaScript are dependency-free static files of approximately
  49 KB, 63 KB and 20 KB respectively before transfer compression.
- The two optional desktop hero video encodings are approximately 1.73 MB and
  2.15 MB. Only the browser-supported source is fetched, and neither source is
  assigned under constrained/mobile conditions.
- All content images are compressed WebP except the intentional brand/source
  files. An older tracked `world-2.jpg` is unreferenced and therefore creates no
  page request; it remains recoverable history rather than an active payload.
- A public PageSpeed API request was rate-limited and the local Lighthouse
  process could not complete within the host's available memory. No invented
  Lighthouse score or Core Web Vitals result is reported. Search Console field
  data should be monitored after sufficient real traffic exists.
