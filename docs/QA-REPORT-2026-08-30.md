## Performance observations

- HTML, CSS and JavaScript are dependency-free static files of approximately
  49 KB, 63 KB and 20 KB respectively before transfer compression.
- The two optional desktop hero video encodings are approximately 1.73 MB and
  2.15 MB. Only the browser-supported source is fetched, and neither source is
  assigned under constrained/mobile conditions.
- All content images are compressed WebP except the intentional brand/source
  files. An older tracked `world-2.jpg` is unreferenced and therefore creates no
  page request; it remains recoverable history rather than an active payload.
- A public PageSpeed API request was initially rate-limited and the local
  Lighthouse process could not complete within the host's available memory.
  The PageSpeed Insights web audit subsequently completed against
  `https://www.baholoprojects.co.za/` using Lighthouse 13.4.1, an emulated Moto
  G Power and slow 4G. It reported 92 Performance, 100 Accessibility, 100 Best
  Practices and 100 SEO, with FCP 0.9 s, LCP 3.0 s, TBT 0 ms, CLS 0 and Speed
  Index 4.1 s. These are lab measurements, not field Core Web Vitals; Search
  Console field data should still be monitored after sufficient real traffic
  exists.

## Open production validations

1. **Lead analytics:** `generate_lead` is registered as a GA4 key event and the
   form-start/submit pipeline appeared in Realtime. The labelled unique lead was
   stored before the acknowledgement fix could return success to the browser;
   the corrected duplicate test intentionally did not count as a new lead. The
   next genuine newly stored consented enquiry remains the final live
   observation for this key event.
2. **Business Profile:** the service-business draft is saved but not public.
   Replace Google's broad automatic `South Africa` service area with accurate
   named areas and complete verification using the real private operating or
   mailing address.
3. **Search favicon observation:** Google had updated the homepage title and
   description but still rendered its generic fallback icon. The deployed
   source prioritises crawlable 48×48 and 192×192 Baholo PNG icons; Google must
   recrawl and reprocess the favicon separately.
4. **Legal sign-off:** the matched privacy notice and terms require review by a
   qualified South African privacy/legal professional, including the stated
   enquiry-retention period and responsible-party contact process.
